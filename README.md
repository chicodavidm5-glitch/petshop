# 🐾 PET SHOP ONLINE

Tienda en línea para perros y gatos hecha con **HTML, CSS y JavaScript** (sin instalar nada).

## Funciones
- Inicio con logotipo, menú, buscador, carrito, registro/inicio de sesión, "Comprar ahora", productos destacados y ofertas.
- Catálogo por categorías: alimentos para perro, alimentos para gato, camas y accesorios.
- Carrito: agregar, eliminar, cambiar cantidad, subtotal y total.
- Registro de clientes, proceso de compra con métodos de pago y confirmación del pedido.
- Panel del administrador: productos (agregar/editar/eliminar), existencias, precios, promociones, compras, ventas y cuentas.

## Administrador de prueba
- Correo: `admin@petshop.com`
- Contraseña: `admin123`  (cámbiala o elimina esta cuenta antes de usar en serio)

## Fotos reales de los productos
Pon tus fotos en la carpeta `images/` con el **id del producto** como nombre: `p1.jpg`, `p2.jpg`, … `p8.jpg`.
Si no hay foto, se muestra una ilustración. Los productos nuevos pueden usar el campo "URL de imagen" en el panel.

## Publicar en GitHub Pages
1. Crea un repositorio en GitHub y sube todos estos archivos (`index.html` en la raíz).
2. Ve a **Settings → Pages**.
3. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
4. En un minuto tu tienda estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Importante
Es una versión de demostración: los datos (cuentas, pedidos, productos) se guardan solo en el navegador (`localStorage`) y los pagos son simulados. Para una tienda real necesitas un servidor/base de datos y una pasarela de pago.
